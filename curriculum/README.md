# gas-craft
 Curriculum Kit

This directory contains resources for instructors teaching Google Apps Script with the gas-craft
 framework.

## Structure

- **Assignment Templates**: (Links to come) Google Docs with problem statements and starter script IDs.
- **Instructor Guides**:
    - `Unit-Plan-4-Week.md`: A 4-week crash course plan.
    - `Unit-Plan-8-Week.md`: An extended semester module plan.
- **Rubrics**: Standard grading rubrics for code quality and functionality.
- **Grading Helpers**: (To be added) Scripts to help batch-process student submissions.

## Getting Started

1. Review the **Instructor Guide** for your desired unit length.
2. Make copies of the **Assignment Templates** for your class.
3. Have students use the library Script ID found in the main README.
